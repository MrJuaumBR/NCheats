JSON API reference

Static, public JSON files containing the same cheat records used by the NCheats browser library. No API key or account is required.

Base URL and endpoints

https://mrjuaumbr.github.io/NCheats/api/v1/

GET index.json

Version, build time, counts and endpoint URLs.

GET platforms/switch.json

All Switch titles and cheats.

GET platforms/3ds.json

All 3DS titles and cheats.

GET platforms/gba.json

All GBA titles and cheats.

GET openapi.json

OpenAPI 3.1 description of the read endpoints.

This is a static read-only API: query parameters do not filter or search on the server, and there are no write, pagination or dynamic game-lookup routes. Fetch the three platform documents to retrieve the complete library, or fetch just one platform to keep downloads smaller.

Response shape

Each document includes apiVersion and generatedAt. Platform documents add an id, platform name, sources and counts. Each game record contains an ID, name, publisher, optional icon, and its cheats.

{
  "apiVersion": "1.0.0",
  "generatedAt": "2026-11-04T00:00:00.000Z",
  "id": "switch",
  "name": "Nintendo Switch",
  "count": { "games": 1, "gamesWithCheats": 1, "cheats": 1 },
  "games": [{
    "id": "0100000000010000",
    "name": "Example game",
    "publisher": "",
    "cheats": [{ "name": "Example cheat", "codes": ["00000000 00000000"] }]
  }]
}

The example values above illustrate the schema only. Use the live JSON for current counts and records.

Usage examples

Fetch from JavaScript

const response = await fetch(
  'https://mrjuaumbr.github.io/NCheats/api/v1/platforms/switch.json'
);
if (!response.ok) throw new Error(`HTTP ${response.status}`);
const data = await response.json();
const marioGames = data.games.filter((game) =>
  game.name.toLowerCase().includes('mario')
);

Fetch with curl

curl https://mrjuaumbr.github.io/NCheats/api/v1/platforms/switch.json
curl https://mrjuaumbr.github.io/NCheats/api/v1/platforms/3ds.json
curl https://mrjuaumbr.github.io/NCheats/api/v1/platforms/gba.json

For smaller downloads, prefer the relevant per-platform endpoint. Snapshots are rebuilt with node scripts/build-api.js (Node.js 18+ and network access to the current blawar/titledb Switch fallback). Cheat data is attributed to FlagBrew / Sharkive, blawar / titledb and RetroArch / libretro-database; see each source for its terms. NCheats is not affiliated with Nintendo.
