3DS, Switch & GBA Cheats

A collection of cheats for Nintendo 3DS, Nintendo Switch and Game Boy Advance.

Getting Started

Here's how to get started with using the cheats:

  1. Pick the Switch, 3DS or GBA tab.
  2. Start typing a game name (or a 16-character title ID on Switch/3DS).
  3. The library loads once and caches in memory for instant search.
  4. Click a game to see every available cheat.
  5. Hit Copy to grab a cheat code block.

About this tool

A small, distraction-free browser for cheat codes on Nintendo 3DS, Nintendo Switch and Game Boy Advance. Everything runs in your browser — no tracking, no accounts.

Cheat codes — Sharkive & libretro-database

Switch and 3DS cheat codes are pulled live from the Sharkive release database, maintained by FlagBrew. GBA cheat codes come from the community-aggregated RetroArch / libretro-database cheats file.

github.com/FlagBrew/Sharkive

Game data — NLib & 3DSDB

Switch & 3DS title metadata (covers, publishers, release info) is looked up through the free NLib API, with 3DSDB as a fallback for 3DS titles not yet indexed by NLib. GBA titles are indexed directly by their in-game names.

api.nlib.cc
