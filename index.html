Getting Started

Here's how to get started with using the cheats:

  1. Pick the Switch, 3DS or GBA tab.
  2. Start typing a game name (or a 16-character title ID on Switch/3DS).
  3. The library loads once and caches in memory for instant search.
  4. Click a game to see every available cheat.
  5. Hit Copy to grab a cheat code block.

fetch('https://mrjuaumbr.github.io/NCheats/api/v1/platforms/switch.json')
  .then((response) => response.json())
  .then((data) => console.log(data.games));

GitHub Pages serves static files: this API is read-only and does not process filters, searches or query parameters on the server. These three platform feeds together contain every bundled cheat; download one or fetch all three, then filter their games arrays in your app. Data is a snapshot; it changes when the repository’s datasets are refreshed.

About this tool

A small, distraction-free browser for cheat codes on Nintendo 3DS, Nintendo Switch and Game Boy Advance. Everything runs in your browser — no tracking, no accounts.

Cheat codes — Sharkive, titledb & libretro-database

The versioned JSON snapshots include Switch codes from FlagBrew / Sharkive and blawar / titledb, 3DS codes from FlagBrew / Sharkive, and GBA codes from the community-aggregated RetroArch / libretro-database cheats file. The library and public API use the same checked-in cheat-data snapshot.

github.com/FlagBrew/Sharkive

Game data — bundled title metadata

Available Switch and 3DS title names and publisher details are Included Switch and 3DS title names and publisher details are available in each JSON snapshot. Source metadata comes from NLib and 3DSDB; GBA titles use the names in their source dataset. Searching the library does not send a request to a metadata service.
